Este repositório documenta meu processo de aprendizagem na plataforma **Microsoft Azure**. Ao longo do caminho, capturei prints, anotei insights importantes e explorei diversas possibilidades que a nuvem da Microsoft oferece.

## 🔍 Sobre o Projeto

- Ajudar outras pessoas que estão iniciando seus estudos na nuvem

# 📝 Anotações Complementares

## Azure Portal
- Interface web principal do Azure
- Permite criar, configurar e monitorar recursos

## Azure Resource Groups
- Unidade lógica para agrupar serviços relacionados
- Ideal para aplicar políticas e monitoramento de forma centralizada

## Azure Virtual Machines
- Custo depende de tipo de VM, região e tempo de uso
- Possível automatizar criação com scripts

## Azure Storage
- Alta disponibilidade e durabilidade
- Controle de acesso com SAS (Shared Access Signatures)

## Azure App Services
- Suporte para várias linguagens: .NET, Java, Node.js, Python
- Integração com GitHub para CI/CD
